# RepoSync

Safe, reliable Git sync for Android folders.

RepoSync mirrors a Git repository into a local folder using the Storage Access Framework (SAF). It supports HTTPS token and SSH key authentication, background sync with WorkManager, conflict awareness, and a mirror-first safety model.

## Features
- SAF-based folder access (no all-files permission)
- Mirror sync engine with conflict handling
- HTTPS token & SSH key auth
- Background sync with WorkManager
- No telemetry, no ads

## Get started
1. Clone the repo and open it in Android Studio.
2. Build and run on a device.
3. Create a profile, choose a target folder, and set the Git remote.
